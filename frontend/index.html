Data sources

Turn each job-data feed on or off. Free feeds cost nothing; paid feeds add a monthly subscription and broaden coverage. Disabling a feed removes its leads from your Daily Leads queue. Most feeds need an API key — even some free ones — so connect them below before enabling.

Adzuna and USAJOBS issue a free API key; SerpApi and the Indeed vendor give you a paid key after you subscribe. Greenhouse and Lever read public boards and need no key. Indeed has no public search API and isn't in Google Jobs, so its coverage comes through a licensed data vendor that runs the scraping — a ToS gray area, enabled only if needed. In production, keys are stored encrypted on the server, never in the browser like this prototype.

Candidate profile — narrative intake

Answer in your own words. We turn each answer into structured criteria (open "What we understood" to see and edit it), and you set how much each one matters.

Importance (1–5) decides how strict each preference is. Low = we widen the search around it; high = we hold the line. That's why pay is a target with an importance — not a hard floor.
